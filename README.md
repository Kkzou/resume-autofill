# 秋招简历助手

一个 Chrome 插件：在各家公司的校招网申页面上，一键把你的简历信息填进表单；还可以按岗位 JD 用 AI 把经历描述改得更贴合岗位。

- **只填有把握的**：标签认得、资料里也有，才填。认不出或资料里没有的（性别、身份证号、政治面貌、GPA……）一律留空，用橙色虚线框标出来等你补。
- **填过一次就记住**：你手动填的、改过的内容会自动记下来，下次在任何网站遇到同一个字段（叫法不同也认，如「身份证号 / 证件号码」）直接填上。
- **附件自己认**：选一个文件夹，插件认出里面哪些是简历、证件照、成绩单、毕业证……网申页面要哪种就传哪种。
- **按岗位定制**（可选，需要 AI）：读取岗位 JD → 归纳这家公司的生态位、最看重的能力和关键词 → 只用你简历里已有的事实改写每段经历 → 自动标出可疑的地方让你核对。
- **不会替你提交**：它只填表，提交 / 保存按钮永远由你自己点。
- **数据在本机**：资料、附件、填写记录都存在你自己的浏览器里。只有你主动使用 AI 功能时，简历正文才会发给你配置的 AI 服务。

> 目前是在模拟 Ant Design / Element UI 结构的表单和原生表单控件上做的自动化测试，还没有在真实招聘网站上逐个验证。识别不了的字段会留空提示，不会乱填。

## 安装

1. 下载代码：`git clone https://github.com/Kkzou/resume-autofill.git`（或在 GitHub 页面点 Code → Download ZIP 后解压）。
2. 打开 Chrome，地址栏输入 `chrome://extensions`，打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择 `resume-autofill` 文件夹。
4. 点浏览器右上角的拼图图标，把「秋招简历助手」固定到工具栏。

## 第一次使用

装好后会自动打开设置页，按顺序做三件事：

| 步骤 | 在哪 | 做什么 |
| --- | --- | --- |
| 1. 填资料 | 我的资料 | 把教育、实习、项目等填进去（左边中文、右边英文），点「保存资料」。只有一种语言的字段可以点「AI 补齐缺的英文 / 中文」 |
| 2. 导附件 | 附件 | 点「选择文件夹…」，选你放简历、证件照、成绩单的文件夹；核对识别结果后导入 |
| 3. 配 AI（可选） | 设置 | 到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 免费申请一个 Gemini API Key，粘贴进去，点「测试连接」 |

第 3 步不做也可以：每个 AI 功能都能「复制提示词」到 ChatGPT、Gemini、Claude 等网页版，再把回复贴回来。

## 日常使用

1. 打开某家公司的网申页面，登录，进到「填写简历」那一页。
2. 点工具栏上的插件图标 → **一键填写当前页面**（或快捷键 `Alt/Option + Shift + F`）。
3. 页面右下角出现面板：

   | 面板上的数字 | 含义 | 你要做什么 |
   | --- | --- | --- |
   | 已填好（绿） | 已经替你填了，或页面上本来就是对的 | 扫一眼确认 |
   | 待你补充（橙） | 不确定、不敢填的 | 点「定位」跳过去，直接在网页上填 |
   | 与资料不一致（红） | 页面上已有内容，但和你的资料不同 | 想换就点「改用资料的值」 |

4. 你在网页上补充的内容会自动记住。表单有好几页的，每到新的一页点右下角的「简历助手 · 填写本页」。
5. 检查无误后，自己点网站的「保存 / 提交」。

几个常见情况：

- **网站有「上传简历自动解析」**：先让它解析完，再点「填写空白项」。解析错的会出现在「与资料不一致」里。
- **教育 / 实习 / 项目有好几段**：页面上有几个空位就填几段，面板会提示还有几段没位置填。先点网站自己的「添加」，再点一次「填写空白项」。已经填过或已保存在页面上的不会重复填。
- **页面只有「工作经历」没有「实习经历」**：面板会问你要不要把实习填进去，选一次就记住。
- **同一类附件有好几个**（比如几个版本的简历）：在「附件」页点 ☆ 设一个默认，就会自动上传它；没设默认时面板里让你选。身份证件类永远由你手动点选。

## 按岗位定制

1. 在岗位详情页点插件图标 → **读取本页 JD，去定制**（也可以在设置页「岗位定制」里新建岗位、手动粘贴 JD）。只想要页面上的某一段，就先用鼠标选中它。
2. **分析岗位**：AI 归纳公司的生态位和出发点、岗位要做的事、最看重的能力（附 JD 依据）和一组关键词。来自 JD 的和来自「行业通常看重」的会分开标注。
3. **调整关键词**：点一下停用 / 启用；在输入框里加你自己想覆盖的关键词。
4. **生成定制描述**：每段经历「原文 / 定制」左右对照，可以直接改。同时给出自我评价、经历的建议排列顺序。
5. 之后在这家公司的网申页面点「一键填写」，用的就是这份定制描述。换到别的网站第一次填写时，面板会先问你要不要用——不会擅自套用到别的公司。

防编造是这个功能的底线，做了三层：

- **提示词里的硬性规则**：只能用你资料里已有的事实，禁止新增经历、数字、职责、工具、成果；关键词只在确有依据时嵌入，没依据的不写，单独列在「没有写进去的关键词」里。
- **本地核对**：生成后自动比对，定制文字里出现了原文没有的数字、英文专有名词，会用红色标出来。
- **你来定**：AI 想让你补充的信息以【待确认】列出，它不会自己编；每一段都可以关掉「填写时使用」。

免费版 Gemini 不能联网检索。想让公司层面的分析更准，把公司官网的介绍、业务说明粘贴到「公司资料」里；否则这部分靠模型已有的知识，页面上会注明「可能过时，需要你核实」。

## AI 与隐私

- 发给 AI 的内容：教育、实习、项目、技能这些简历正文，岗位 JD，你粘贴的公司资料。
- **不会**发给 AI：姓名、电话、邮箱、证件号、任何附件文件。
- Gemini 的免费层会把提交的内容用于改进 Google 的产品。介意的话请使用付费层，或者只用「复制提示词」的方式。
- 免费层有每分钟、每天的调用次数上限（以 AI Studio 里显示的为准）。分析一个岗位 1 次、生成定制描述 1 次、补齐译文 1 次。
- API Key 只保存在本机浏览器的扩展存储里，不会写进备份文件，也不在代码仓库里。
- 默认模型是 `gemini-3.5-flash-lite`。点「测试连接」时，如果填的模型不可用，会自动换成当前最新的稳定版 Flash-Lite。

## 它会填什么、不会填什么

| 类型 | 处理方式 |
| --- | --- |
| 姓名、手机、邮箱、学校、专业、学历、起止时间、实习、项目、技能、奖项 | 资料里有 → 自动填 |
| 手机号 / 邮箱有两套 | 中文表单用左边一套，英文表单用右边一套；可在设置里固定用某一套 |
| 性别、出生日期、身份证号、政治面貌、民族、籍贯、GPA、学院、期望薪资等 | 资料里没有 → 不填，等你填一次后记住 |
| 自我评价 | 只在为当前岗位生成过定制内容时才填 |
| 紧急联系人、家庭成员、推荐人 | 绝不拿你本人的信息去填，只用你填过的记录 |
| 密码、验证码 | 不填、不记 |
| 勾选框（同意条款、「至今」等） | 不碰 |
| 下拉 / 单选 | 选项里有唯一对得上的才选（「硕士」能对上「硕士研究生」）；对不上或有歧义就留给你 |
| 需要具体到「日」的日期 | 资料只写到月份时不会编一个日子，留给你 |
| 多级联动下拉、只能点选的日历、富文本编辑器 | 目前留给你手动；面板会显示资料值方便对照 |

## 常见问题

**点了没反应？** 插件安装或更新之前就打开的网页，需要先刷新一下。

**改了代码不生效？** 到 `chrome://extensions` 点插件卡片上的刷新图标，再刷新网页。

**快捷键不管用？** 可能被别的插件占用了，到 `chrome://extensions/shortcuts` 重新设一个。

**填错了 / 记错了？** 设置页 → 填写记录，可以改或删。

**换电脑？** 设置页 → 设置 → 导出备份，在新电脑上「从备份恢复」。附件需要在新电脑上重新选一次文件夹。

**不要在 `chrome://extensions` 里点「移除」**——移除会清空浏览器里保存的资料、附件和填写记录。要挪动文件夹，先导出备份。

## 开发

```
resume-autofill/
├── manifest.json
├── src/
│   ├── background.js        后台：初始化、转发「一键填写」和「读取本页 JD」
│   ├── lib/
│   │   ├── text.js          文本规整、日期解析
│   │   ├── store.js         存储封装
│   │   ├── files.js         附件：类型、按文件名 / 正文识别、存取
│   │   └── ai.js            AI：接口调用、三个任务的提示词、本地防编造核对
│   ├── content/             注入网页的部分
│   │   ├── rules.js         标签 → 字段 的识别规则（想扩充叫法改这里）
│   │   ├── resolve.js       字段 → 资料里的值；下拉选项的同义词
│   │   ├── dom.js           读页面：字段、标签、分区、分段
│   │   ├── widgets.js       往各种控件里写值并校验
│   │   ├── memory.js        填写记录
│   │   ├── panel.js         右下角面板
│   │   └── main.js          主流程
│   ├── popup/               工具栏弹窗
│   └── options/             设置页（资料 / 岗位定制 / 附件 / 填写记录 / 设置）
├── examples/profile.example.json   资料格式示例
├── private/                 你自己的资料（已被 .gitignore 排除，不会进仓库）
└── test/                    模拟表单 + 端到端测试
```

运行测试（不需要安装任何依赖，用本机 Chrome 以无界面方式真实加载插件；AI 接口由本地假服务代替，不需要 API Key）：

```bash
node test/e2e.mjs
```

想接别的模型（比如 Claude）：在 `src/lib/ai.js` 的 `PROVIDERS` 里加一个 `{ generate, models, pickModel }`，提示词和界面都不用动。

想让插件认识某个网站特有的字段叫法：在 `src/content/rules.js` 对应规则的列表里加上那个标签原文。

`private/` 目录是可选的：把 `examples/profile.example.json` 复制为 `private/profile.json` 并改成自己的信息，首次安装时会自动导入。这个目录已被 `.gitignore` 排除。
